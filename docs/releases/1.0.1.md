## Fixes in 1.0.1

- Fix the launch crash reported on HyperOS / Android 14 in [issue #1](https://github.com/suddenBook/GPTWake/issues/1). The event log now has a finite scrolling height.
- Keep all controls reachable on phones, tablets, landscape windows, and at larger font sizes.
- Apply sensitivity changes to the native recognizer immediately and save them across restarts.
- Replace the previous wake phrase when applying a new one; the default phrase no longer remains armed alongside it.
- Prevent delayed launches and microphone restarts after Stop, and keep keyword edits from interrupting an active voice session.
- Pause capture when a phone or VoIP call starts and resume when it ends. Report microphone failures instead of showing a false listening state.
- Remember Start/Stop across reboot; new installations wait for setup and the first Start.
- Fix Android 12L compatibility, mixed English/Chinese tokenization, and short-phrase syllable warnings.
- Pause UI polling and animations while the activity is stopped. Preserve wake-word drafts through recreation.
- Add regression tests and release lint checks, and preserve 16 KB APK alignment during signing.
- Keep diagnostic JSON valid across locales, preserve event ordering, and record the current keyword hash.

Version code: **2**. This release keeps the same on-device model and requires no new permissions.
